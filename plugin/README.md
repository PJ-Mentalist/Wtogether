# Wtogether для exteraGram

Плагин для совместного просмотра видео прямо в личном чате Telegram. Пауза, перемотка и скорость общие у обоих. Поверх видео видны аватарки участников и удобные кнопки, можно переписываться и созвониться.

## Установка

1. exteraGram 12.5.1 или новее. Настройки exteraGram → «Плагины» → включить движок плагинов.
2. Отправь себе файл `wtogether.plugin` (например, в «Избранное») и нажми на него → «Установить».
3. Плагин нужен у обоих собеседников.

## Как смотреть

1. Долгое нажатие на видео в личке → **Плагины → «🎬 Смотреть вместе»**. Другу уйдёт приглашение.
2. У друга появится окно **«Смотреть / Отказаться / Позже»**.
3. Оба открывайте это видео. Кто подключился позже, тот сам догонит позицию.
4. Поверх видео появятся:
   - **аватарки** вверху справа: зелёная точка — друг тоже смотрит; нажатие открывает панель;
   - **кнопки** над ползунком: −10 с, ▶/⏸, +10 с, 💬 сообщение, 📞 звонок. Скрываются вместе с панелями плеера по нажатию на видео.
5. **💬 Сообщения** всплывают поверх видео у обоих с привязкой к моменту. Когда закончишь просмотр, они уйдут в чат одним сообщением «Обсуждали видео вместе» с таймкодами.
6. **📞 Голос** запускает обычный звонок Telegram: можно обсуждать голосом и смотреть дальше.
7. Меню чата (⋮) → **«🎬 Wtogether»** — панель: статус друга, «Подтянуть друга», «Закончить», отправить обсуждение.

## Иконка

`icon.png` (512×512) — иконка плагина. exteraGram берёт иконку плагина из набора стикеров:

1. Напиши боту [@Stickers](https://t.me/Stickers): `/newpack` → название → отправь `icon.png` **файлом** → любой эмодзи → `/publish` → придумай короткое имя, например `wtogether_icons`.
2. В начале `wtogether.plugin` замени строку `__icon__ = "exteraPlugins/1"` на `__icon__ = "wtogether_icons/0"`.

## Как это устроено

Команды идут тихими служебными сообщениями с меткой `#wt1`. У друга плагин их скрывает, а у отправителя они удаляются с сервера через 3 секунды. Сервер не нужен: всё идёт через сам Telegram.

## Ограничения

- Только личные чаты и только видео, отправленные в чат.
- Telegram ограничивает частоту сообщений, поэтому быстрые перемотки склеиваются в одну команду.
- Если у друга нет плагина, он увидит служебные сообщения на пару секунд.
- Плагин использует внутренние классы Telegram (`PhotoViewer`, `VideoPlayer`, `VoIPHelper`). После крупных обновлений exteraGram его может понадобиться поправить.

## Если что-то не работает

Включи в «Плагинах» режим разработчика и пришли логи с тегом `plugin.wtogether`.
