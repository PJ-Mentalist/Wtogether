# Wtogether для exteraGram

Совместный просмотр видео прямо в Telegram. Кто позвал — ведущий 👑: только он управляет видео, у зрителей пауза, перемотка и скорость повторяют его. Зрителей может быть несколько.

## Установка

1. exteraGram 12.5.1 или новее. Настройки exteraGram → «Плагины» → включить движок плагинов.
2. Отправь себе файл `wtogether.plugin` (например, в «Избранное») и нажми на него → «Установить».
3. Плагин нужен у всех участников.

## Как смотреть

1. Открой видео в личке с другом. Внизу появится кнопка **«🎬 Смотреть вместе»**. Нажми — ты ведущий 👑, другу уйдёт приглашение. (Или долгое нажатие на видео → Плагины → «Смотреть вместе».)
2. У друга появится окно **«Смотреть / Отказаться / Позже»**.
3. **Ещё зрители:** перешли это же видео другому другу, открой его в том чате и снова нажми «Смотреть вместе». Друг попадёт в то же лобби.
4. Поверх видео:
   - **головы участников** вверху справа, у ведущего корона 👑. Точка: 🟢 смотрит, ⚪ ещё не открыл видео, 🟠 не ответил. Нажатие открывает список всех участников;
   - **кнопки ведущего:** −10 с, ▶/⏸, +10 с, 💬, 📞, ➕;
   - **кнопки зрителя:** 🔄 догнать ведущего, 💬, 📞. Если зритель сам нажмёт паузу или перемотает, плагин вернёт его к ведущему.
5. **💬 Сообщения** всплывают поверх видео у всех. Когда ведущий заканчивает просмотр, обсуждение уходит в чаты одним сообщением с таймкодами.
6. **📞 Звонок** — обычный звонок Telegram. У ведущего с несколькими зрителями — выбор, кому звонить.
7. Меню чата (⋮) → **«🎬 Wtogether»** — та же панель.

## Если кнопки не появляются

Настройки плагина → **«🛠 Проверка работы»**. Там видно, какие части Telegram плагин нашёл и какие были ошибки. Нажми «Скопировать» и пришли текст.

## Иконка

`icon.png` (512×512). exteraGram берёт иконку плагина из набора стикеров:

1. Напиши боту [@Stickers](https://t.me/Stickers): `/newpack` → название → отправь `icon.png` **файлом** → любой эмодзи → `/publish` → короткое имя, например `wtogether_icons`.
2. В начале `wtogether.plugin` замени `__icon__ = "exteraPlugins/1"` на `__icon__ = "wtogether_icons/0"`.

## Как это устроено

Лобби — это ведущий и зрители, каждый в своём личном чате с ведущим. Команды идут тихими служебными сообщениями с меткой `#wt1`: у получателя плагин их скрывает, у отправителя они удаляются с сервера через 3 секунды. Сообщения зрителей ведущий пересылает остальным. Сервер не нужен.

## Ограничения

- Только личные чаты. Групповые чаты пока не поддерживаются.
- Telegram ограничивает частоту сообщений: быстрые перемотки склеиваются в одну команду, а с большим числом зрителей синхронизация чуть медленнее.
- Плагин использует внутренние классы Telegram (`PhotoViewer`, `VideoPlayer`, `VoIPHelper`). После крупных обновлений exteraGram его может понадобиться поправить.
