# Wtogether для exteraGram 4.0

Смотрим видео вместе прямо в Telegram. Кто создал комнату — ведущий 👑: он управляет, у остальных всё повторяется само. **В чат ничего не пишется**, кроме приглашения — связь идёт отдельно.

## Установка

1. exteraGram 12.5.1 или новее. Настройки exteraGram → «Плагины» → включить движок плагинов.
2. Отправь себе `wtogether.plugin` (например, в «Избранное»), нажми на него → «Установить» (поверх старой версии).
3. Плагин нужен у всех участников.

## Как смотреть

1. **Комната:** долгое нажатие на видео → Плагины → **«🎬 Смотреть вместе»**. Или меню Wtogether → **«Смотреть по ссылке»** (YouTube, `.mp4`, `.m3u8`). Код комнаты — **4 цифры**.
2. **Позвать:** «Пригласить» — в чат уходит карточка с кнопкой-ссылкой **«▶️ Войти в комнату»**: другу достаточно нажать (вход в один тап). Или продиктуй код — друг вводит его в «Войти по коду».
3. **Лобби:** у ведущего карточка «Комната 4821» с участниками и полосками загрузки, кнопка **«Начать для всех»** → отсчёт 3‑2‑1 у всех.

Меню Wtogether: меню чата ⋮ → «🎬 Wtogether», боковое меню → «Wtogether», настройки плагина.

## Плеер

Оформление в стиле exteraGram: иконки Telegram, плавающая панель-«пилюля», цвета темы, анимации.

- **Сверху:** закрыть, название, «Комната 4821 · 👑 ведёт …», аватарки участников (🟢 готов, 🟠 загружает, 👑 ведущий) — нажми, чтобы увидеть всех.
- **Ведущий:** ⟲10, ▶/⏸, 10⟳, скорость, реакции, чат, «⋯».
- **Зритель:** ✋ «Подожди меня», ⟳ догнать, реакции, чат, «⋯». Ползунок заблокирован.
- **Меню «⋯»:** пригласить, **передать управление 👑**, участники, звонок, **мини-плеер**, повернуть экран, выйти.
- **Жесты:** двойной тап слева/справа — ±10 с, по центру — пауза; свайп вбок — перемотка; вверх-вниз справа — громкость, слева — яркость. Зрителю жесты управления показывают «🔒 Управляет …».
- **Реакции:** ❤️😂🔥😱👏😭🤯💀 вылетают поверх видео у всех.
- **Чат сбоку**, как в стримах: история с таймкодами, значок непрочитанных; когда чат закрыт — сообщения всплывают слева.
- **✋ Подожди меня:** ведущий автоматически ставит паузу (или получает запрос с кнопкой — в настройках).
- **Мини-плеер:** окошко поверх Telegram, можно перетаскивать и переписываться в чатах; нажми — развернуть. При звонке плеер сворачивается сам.

## Как устроена связь

- Публичный бесплатный MQTT-брокер (`broker.emqx.io`, запасные — HiveMQ и Mosquitto). Первая цифра кода говорит, на каком брокере комната. Если брокер недоступен, ведущий сам переезжает на следующий.
- MQTT-клиент встроен в плагин на чистом Python — ничего ставить не нужно.
- Состояние комнаты хранится на брокере: опоздавший сразу получает позицию и скорость. Пропавший из сети участник исчезает из списка.
- Зритель сверяет часы с ведущим и держится рядом: до 0,15 с — ничего, до 2 с — плавно ускоряется или замедляется, дальше — перематывает. Для YouTube (только фиксированные скорости) — перемотка при расхождении больше 0,7 с.

⚠️ Брокер публичный, а код короткий (4 цифры): посторонний теоретически может подобрать код и зайти в комнату. Видео при этом не передаётся — у каждого своё.

## Тесты

- `python3 plugin/tools/test_room.py` — локальный MQTT-брокер и сценарий с ведущим и зрителями: занятость кода, участники, часы, отсчёт, чат, реакции, «подожди», опоздавший, передача 👑, обрыв, завершение, повторное использование брошенного кода (24 проверки).
- `python3 plugin/tools/sync_sim.py plugin/wtogether.plugin` — симуляция подстройки зрителя к ведущему.

## Если что-то не работает

Настройки плагина → **«🛠 Проверка работы»** → «Скопировать» и пришли текст: сервер, связь, участники, сдвиг часов, каких иконок не нашлось, ошибки.

## Иконка

`icon.png` (512×512): [@Stickers](https://t.me/Stickers) → `/newpack` → отправь `icon.png` файлом → эмодзи → `/publish` → короткое имя (например `wtogether_icons`). Затем в начале `wtogether.plugin`: `__icon__ = "wtogether_icons/0"`.
