# Wtogether — сборка APK

Всё приложение — один файл `www/index.html`. Сервер и хостинг не нужны: устройства связываются напрямую.

## Готовый APK

Каждый push в `main` запускает GitHub Actions (`.github/workflows/build-apk.yml`). Готовый `Wtogether.apk` появляется в разделе **Releases** репозитория — его удобно скачать прямо с телефона.

## Сборка вручную через Capacitor

Нужны Node.js и Android Studio.

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

В Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

Плагин `cordova-plugin-inappbrowser` — это встроенный браузер для совместного просмотра сайтов. Без него всё остальное работает, а сайты открываются в обычном браузере без синхронизации.

## Первый запуск

1. Вкладка «Профиль»: придумай @юзернейм (латиница, цифры, _), поставь аватарку.
2. «Комната» → «Создать приглашение» → отправь код другу.
3. Друг: «Войти по приглашению» → вставляет код → отправляет тебе ответ.
4. Ты вставляешь ответ → «Подключить». Для каждого следующего гостя — новое приглашение.

## Что можно смотреть вместе

| Источник | Как | Синхронизация |
|---|---|---|
| Файлы на телефоне | «Файл» | видео, страницы манги, прокрутка книг |
| YouTube | «Ссылка» | пауза, перемотка, скорость |
| Прямая ссылка на видео (.mp4, .m3u8) | «Ссылка» | пауза, перемотка, скорость |
| Любой сайт (аниме, фильмы, манга, книги) | «Ссылка» | видео на странице, прокрутка, переход на другую страницу или серию |

На сайте внизу справа появляется кнопка «Чат» и сообщения друзей. Если плеер сайта встроен во фрейм, появится кнопка «Открыть плеер для совместного просмотра». Чтобы вернуться в приложение с сайта, нажми «Комната» в верхней панели сайта.

## Библиотека

- Статусы: смотрю / в планах / завершено / брошено, номер серии или главы, обложка, заметка, ссылка.
- Каждый ставит свою оценку 1–10, видна общая средняя и оценки друзей с аватарками.
- «Смотрим вместе с»: такие записи и оценки сами появляются у друзей при подключении к комнате.
- «В библиотеку» во время просмотра заполняет название и номер серии автоматически.

Всё хранится только на телефоне. Во вкладке «Профиль» есть резервная копия для переноса на другое устройство.

## Ограничения

- Сайты с защитой (Netflix, Кинопоиск и т. п.) могут не давать перематывать видео извне.
- Юзернейм уникален только в пределах ваших комнат: общего сервера нет.
- Для сайтов и YouTube нужен интернет у каждого. Файлы работают и в одной Wi‑Fi сети без интернета.
- PDF, CBR, MOBI пока не открываются.
