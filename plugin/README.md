# Wtogether для exteraGram 2.0

Совместный просмотр видео из Telegram в собственном плеере. Кто позвал — ведущий 👑, только он управляет. У зрителей всё повторяется само.

## Установка

1. exteraGram 12.5.1 или новее. Настройки exteraGram → «Плагины» → включить движок плагинов.
2. Отправь себе файл `wtogether.plugin` (например, в «Избранное») и нажми на него → «Установить» (если ставилась старая версия — поверх неё).
3. Плагин нужен у всех участников.

## Как смотреть

1. **Ведущий:** долгое нажатие на видео в личке → Плагины → **«🎬 Смотреть вместе»**. Другу уходит приглашение, у тебя открывается плеер Wtogether.
2. **Зритель:** в окне приглашения жмёт **«Смотреть»** — у него открывается тот же плеер.
3. Видео загружается у каждого. В плеере ведущего видно, кто готов. Ведущий жмёт **«▶ Начать для всех»** — у всех отсчёт 3‑2‑1 и одновременный старт.
4. **Ещё зрители:** перешли видео другому другу и снова «Смотреть вместе» в его чате.

## Плеер

- **Сверху:** закрыть, «👑 Ты ведёшь / Ведёт …», статус («готовы 2 из 3», «на связи»), аватарки участников. Точка: 🟢 готов, 🟠 загружает, ⚪ не ответил. Нажатие — список участников.
- **Снизу у ведущего:** ползунок, −10 с, ▶/⏸, +10 с, скорость (1× → 1.25× → 1.5× → 2× → 0.75×), 📞, ⤢ повернуть.
- **Снизу у зрителя:** ползунок заблокирован, 🔒 «Управляет ведущий», 🔄 догнать, 📞, ⤢.
- **Сообщение всем:** поле ввода внизу. Сообщения всплывают поверх видео, а когда ведущий заканчивает, уходят в чаты одним сообщением с таймкодами.
- Нажатие на видео прячет и показывает панели.

## Как держится синхронизация

- Источник правды — ведущий. Во время воспроизведения он раз в 3 с рассылает позицию, а при паузе, перемотке и смене скорости — сразу.
- Зритель регулярно сверяет часы с ведущим (ping/pong) и каждые 0,3 с сравнивает свою позицию с расчётной:
  - меньше 0,15 с — ничего не делает;
  - 0,15–2 с — на время ускоряется или замедляется на 8%, пока не сойдётся до 0,08 с;
  - больше 2 с — перематывает точно в кадр.
- Старт — по общему отсчёту, зритель встаёт точно в нужную позицию.
- Типичная точность — 0,1–0,3 с. Её ограничивает задержка сообщений Telegram.

Команды — тихие служебные сообщения с меткой `#wt1`. У получателя скрываются (два способа приёма), у отправителя удаляются с сервера пачками каждые 4 с.

## Если что-то не работает

Настройки плагина → **«🛠 Проверка работы»** → «Скопировать» и пришли текст. Там видно, сколько команд ушло и пришло, сдвиг часов, пинг и последние ошибки.

## Иконка

`icon.png` (512×512). Иконка плагина берётся из набора стикеров:

1. [@Stickers](https://t.me/Stickers): `/newpack` → название → отправь `icon.png` **файлом** → эмодзи → `/publish` → короткое имя, например `wtogether_icons`.
2. В начале `wtogether.plugin` замени `__icon__ = "exteraPlugins/1"` на `__icon__ = "wtogether_icons/0"`.

## Ограничения

- Только личные чаты.
- Видео сначала загружается целиком (идёт индикатор).
- Формат видео должен поддерживаться плеером Android (MP4/H.264 — всегда).
