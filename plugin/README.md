# Wtogether для exteraGram 3.0

Совместный просмотр видео из Telegram по коду комнаты. Кто создал комнату — ведущий 👑: только он управляет, у остальных всё повторяется само. **В чат ничего не пишется** — связь идёт отдельно.

## Установка

1. exteraGram 12.5.1 или новее. Настройки exteraGram → «Плагины» → включить движок плагинов.
2. Отправь себе `wtogether.plugin` (например, в «Избранное»), нажми на него → «Установить» (поверх старой версии).
3. Плагин нужен у всех участников.

## Как смотреть

1. **Ведущий:** долгое нажатие на видео → Плагины → **«🎬 Смотреть вместе»**. Появится код комнаты, например `K7P4QD`, и откроется плеер.
2. **Позвать:** «Отправить в чат» (уйдёт одно сообщение с кодом) или «Скопировать» и отправить как угодно. Позвать можно сколько угодно людей — код у всех один.
3. **Зритель:** «Смотреть» во всплывшем окне, когда пришёл код, или **«Войти по коду»**:
   - настройки плагина → «🎟 Войти по коду»;
   - меню чата ⋮ → «🎬 Wtogether» → «Войти по коду»;
   - боковое меню → «Wtogether: войти по коду».

   Плагин сам находит это видео у зрителя (в чате с ведущим, потом во всех чатах) и загружает его.
4. В лобби ведущий видит, кто подключился, кто загружает и кто готов. Кнопка **«▶ Начать для всех»** — отсчёт 3‑2‑1 и одновременный старт.

## Плеер

- **Сверху:** «👑 Ты ведёшь · код K7P4QD» или «👑 Ведёт …», связь, аватарки участников (🟢 готов, 🟠 загружает, ⚪ подключается).
- **Ведущий:** ползунок, −10 с, ▶/⏸, +10 с, скорость, 🔗 код комнаты, 📞, ⤢.
- **Зритель:** ползунок заблокирован, 🔒, 🔄 догнать, 📞, ⤢.
- **Сообщение всем** — внизу, всплывает поверх видео у всех.

## Как устроена связь

- Связь идёт через бесплатный публичный MQTT-брокер (`broker.emqx.io`, запасные — HiveMQ и Mosquitto). Первая буква кода говорит, на каком брокере комната, так что все попадают на один. Если брокер недоступен, ведущий автоматически переезжает на следующий.
- MQTT-клиент встроен в плагин на чистом Python — ничего ставить не нужно.
- Состояние комнаты хранится на брокере: опоздавший сразу получает позицию и скорость. Если у кого-то пропал интернет, остальные видят, что он вышел.
- Зритель сверяет часы с ведущим и держится рядом: до 0,15 с — ничего, до 2 с — плавно ускоряется или замедляется, дальше — перематывает.

⚠️ Брокер публичный: тот, кто угадает код из 6 символов (около миллиарда вариантов), сможет зайти в комнату. Видео при этом не передаётся — у каждого своё из Telegram.

## Тесты

- `python3 plugin/tools/test_room.py` — локальный MQTT-брокер и сценарий «ведущий + зрители»: комната, участники, часы, отсчёт, чат, опоздавший, обрыв связи, завершение (18 проверок).
- `python3 plugin/tools/sync_sim.py plugin/wtogether.plugin` — симуляция подстройки зрителя к ведущему.

## Если что-то не работает

Настройки плагина → **«🛠 Проверка работы»** → «Скопировать» и пришли текст: сервер, связь, участники, сдвиг часов, ошибки.
