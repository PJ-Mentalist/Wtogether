# Wtogether для exteraGram

Плагин для совместного просмотра видео прямо в личном чате Telegram. Пауза, перемотка и скорость общие у обоих.

## Установка

1. exteraGram 12.5.1 или новее. Настройки exteraGram → «Плагины» → включить движок плагинов.
2. Отправь себе файл `wtogether.plugin` (например, в «Избранное») и нажми на него → «Установить».
3. Плагин нужен у обоих собеседников.

## Как смотреть

1. Долгое нажатие на видео в личке → **Плагины → «🎬 Смотреть вместе»**. Другу уйдёт приглашение.
2. У друга появится окно **«Смотреть / Отказаться / Позже»**.
3. Оба открывайте это видео. Кто подключился позже, тот сам догонит позицию.
4. Пауза, перемотка и скорость дальше общие.
5. Меню чата (⋮) → **«🎬 Wtogether»** — панель: статус друга, «Подтянуть друга ко мне», «Закончить».
6. Статус и настройки уведомлений есть и в настройках плагина.

## Как это устроено

Команды идут тихими служебными сообщениями с меткой `#wt1`. У друга плагин их скрывает, а у отправителя они удаляются с сервера через 3 секунды. Сервер не нужен: всё идёт через сам Telegram.

## Ограничения

- Только личные чаты и только видео, отправленные в чат.
- Telegram ограничивает частоту сообщений, поэтому быстрые перемотки склеиваются в одну команду.
- Если у друга нет плагина, он увидит служебные сообщения на пару секунд.
- Плагин использует внутренние классы Telegram (`PhotoViewer`, `VideoPlayer`). После крупных обновлений exteraGram его может понадобиться поправить.

## Если что-то не работает

Включи в «Плагинах» режим разработчика и пришли логи с тегом `plugin.wtogether`.
